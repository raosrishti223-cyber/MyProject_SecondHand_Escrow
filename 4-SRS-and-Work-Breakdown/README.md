## 4. SRS and Work Breakdown

This section contains the Software Requirements Specification (SRS) and the Work Breakdown Structure (WBS) for the Second-Hand Product Escrow Marketplace.

### SRS

The SRS document provides a structured description of the system requirements, including:

* System purpose and scope
* Stakeholders and system actors
* Functional Requirements (FR-001 to FR-005)
* Non-Functional Requirements (NFR-001 and NFR-002)
* Use Cases (UC-01 to UC-05)
* Main use-case flow
* Exception flows
* Acceptance criteria
* Requirements traceability

**File:** `4-SRS-and-Work-Breakdown/SRS.pdf`

### Work Breakdown

The Work Breakdown Structure divides the project into smaller and manageable tasks. It covers:

* Requirements Engineering
* Escrow Management
* Product Inspection
* Buyer Verification
* Dispute Management
* Security
* Testing and Validation
* Documentation and Project Management

**File:** `4-SRS-and-Work-Breakdown/Work_Breakdown.pdf`
