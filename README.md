## Project Description

The Second-Hand Product Escrow Marketplace is a system designed to support secure transactions between buyers and sellers of second-hand products.

The system uses an escrow mechanism to hold the buyer's payment until the product has been inspected and the required approval conditions are satisfied. The system also supports inspection, payment processing, fund release, and dispute handling.

### Architecture Selected

**Microservices Architecture**

The main components identified for the system are:

1. Order Manager
2. Payment Service
3. Inspection Service
4. Escrow Manager
5. Dispute Manager

The main interfaces between the components are:

- Payment Processing API
- Escrow Payment API
- Inspection Report API
- Fund Freeze API
